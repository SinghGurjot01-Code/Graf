## ⚖️ Honest Edge Cases & Tradeoffs

* **The Micro-File Overhead (+25.8% on Task 3.3)**: On tiny files (< 40 lines), returning rich JSON AST schemas consumed 872 tokens vs. 693 tokens for raw file reading. Graf is built for architectural discovery and blast radius analysis.

## 🔌 Quick Agent Setup

Install `Graf-Setup-1.0.3-x64.exe`, then register Graf in your agent's MCP configuration:

```json
{
  "mcpServers": {
    "graf": {
      "command": "%LOCALAPPDATA%\\Programs\\Graf\\resources\\runtime\\node.exe",
      "args": [
        "%LOCALAPPDATA%\\Programs\\Graf\\resources\\core\\src\\mcp\\server.js"
      ],
      "env": {
        "GRAF_PROJECT_ROOT": "${workspaceFolder}"
      }
    }
  }
}
```

For Claude Desktop, Cursor, and Windsurf setups, see the included [Setup Guide](https://github.com/SinghGurjot01-Code/Graf/blob/main/docs/SETUP_GUIDE.md).
